proper (unconditional — proper while … is rejected) renders an entity as a bare name: "You can see Tobias here." It composes on any create block, not only a person: a shop, an institution, or a place written as scenery (create Grubber's Market over scenery, proper) is a name as much as a person is. The create-line article is never read for identity: create the zookeeper and create a zookeeper load identically; if a person is proper-named, say so. A pronouns line names the narration's pronoun set: one of he, she, it, they, or a define pronouns set name. Absent means absent: without the line, a person renders by number ("it"/"they"); nothing is inferred from a name.

create Tobias
  aka groundskeeper
  a person, proper
  pronouns he
  in the Gatehouse

See also Characters & Conversation for the optional layers a person can carry — personality, mood, what they know and want, and how they behave in dialogue.
