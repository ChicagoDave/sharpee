`define verb <word> {or <word>} means <pattern>` teaches the parser a
new surface verb by mapping it onto an existing action's pattern. A
`the <name>` in the pattern is a slot the parser fills from the
player's input:

```chord
define verb hang or hook means put the something on the something
```

`hang the jacket on the hook` and `hook the jacket on the hook` now both
route through the standard `put … on …` action.

For now, `put the something on the something` is the only pattern
`define verb` can map onto — mapping any other pattern is a load error
naming this limit. To define a genuinely new verb with its own grammar
and behavior, use `define action`. General aliasing onto any standard
action arrives with the grammar work in a future release.
