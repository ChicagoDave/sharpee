### (b) Derivations that read as wrong

There are 187 unique ones (the review list is the script's `suspicious` filter). They fall into five classes.

**1. `pluralize` turns every final `f` or `fe` into `ves`.** It gives `staff → stafves`, `skiff → skifves`, `stiff → stifves`, `stuff → stufves`, `roof → rooves`, `reef → reeves`, `beef → beeves` and `safe → saves`. Further checks show `chief → chieves` and `cliff → clifves`. `leaf`, `knife` and `wife` come out right because they are in the irregulars table. This is in the runtime today, in list rendering, and is filed as **#842**.

**2. `singularize` drops only the `s` from `-ves` and `-oes` plurals outside the table.** It gives `bookshelves → bookshelve`, `candle-shelves → candle-shelve`, `loaves → loave` and `echoes → echoe`. This costs a match the player wants (`bookshelf` would not name "bookshelves"), and never makes a false one. The fix is in #842 too.

**3. `pluralize` adds a bare `s` after `-o`.** It gives `volcano → volcanos`, `echo → echos` and `potato → potatos`. A miss, not a false match; also #842.

**4. Possessives and non-nouns are treated as nouns.** `bird's → bird'`, `baker's → baker'`, `brothers' → brothers's`, and `tobias → tobia`, `politics → politic`, `mrs → mr`, `to → tos`, `two → twos`. Numbers and hyphenated adjectives (`1 → 1s`, `maze1 → maze1s`, `one-eyed → one-eyeds`, `#3 → #3s`) belong here too. None is a word a player types, so they add vocabulary nobody uses. The real risk is a derived word equal to another thing's written word, which class (a) counts.

**5. Correct and worth noting.** `men → man`, `leaves → leaf`, `shelves → shelf`, `caves → cave`, `areas → area`, `galagos → galago`, `herbwife → herbwives`, `thief → thieves`, `knife → knives`, `scarf → scarves`.

### (c) Words whose two numbers are the same

These derive nothing. They are the `SAME_IN_BOTH_NUMBERS` set (`sheep`, `deer`, `fish`, `series`, `species`, `bellows`, `tongs`, `scissors`, `shears`, `pliers`, `trousers`) wherever a story uses them.
