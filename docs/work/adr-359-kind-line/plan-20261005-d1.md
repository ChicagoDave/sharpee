Hosts: whole `.story`/`.chord` files; fenced ```chord blocks in website mdx; Chord inside TS/JS template and string literals (found with the TypeScript AST, skipping any literal with `${}` interpolation inside a create block and reporting it for manual edit); Swift/C# string fixtures are reported or handled by a documented host adapter.
