# 08 — Vocabulary

**Created**: 2026-09-11
**Status**: EXPLORATORY — the rule is decided (D5); the table is a first pass

## The rule

The UI uses **Chord's own words**. Not softened equivalents, not a friendlier
synonym layer.

Reason: the Chord tab sits beside the Map tab from minute one (`01`). A child
who has spent an hour dragging *Places* and writing *Words* opens the source
and finds `room` and `description` — the app has taught them a vocabulary that
is wrong everywhere else, including in Chord Writer, the reference, and every
other story they will ever open. Using the real nouns costs nothing at age
nine and pays off permanently.

A gloss in smaller type beside the term is fine and used in several places
(the strategy picker in particular). The gloss goes *underneath* the term,
never instead of it.

## What changed

An earlier pass used a softened set. Recorded here so it is not re-invented.

| Rejected | Chord |
|---|---|
| Place | `room` |
| Ways out | exits (`east to …`) |
| What they see | `description` |
| What it says | `phrase` / `phrases` |
| First time only | `first time` |
| When… | `on…` |
| Points | `score` / `award` |
| Give points | `award` |
| Say (step) | `phrase` (step) |
| Only once | `once` |
| Starts out | `starts` |
| Playing as | `the player` |
| First words | `prologue` |
| Can be played | `playable` |
| Carrying, to begin with | `carries` |
| Only when… | `when` (statement) / `while` (phrase gate) |
| Another version | another variant (`or`) |
| Shuffle them / In order, then loop / … | `randomly` / `cycling` / `stopping` / `first-time` |
| Name of a thing | marker (`{ }`) |

## Where the literal Chord line is the label

Three places show the construct itself rather than a label for it:

- The Start Card's banner reads `BEFORE THE GAME STARTS`.
- The `on…` builder's header reads `on the player` + a gerund picker.
- The phrase rail lists keys (`locked-shut`, `unlocks`), not descriptions of
  them.

## Where plain English still wins

Diagnostics. "Nobody is playing yet" is a better sentence than
`analysis.start-block-no-role`, and the code sits beside it in small type
(`05`). The rule is about the *names of things a child creates*, not about how
the app talks about failure.
