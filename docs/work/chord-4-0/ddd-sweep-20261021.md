# Chord 4.0 — DDD sweep of `main...chord-4-0`

**Date**: 2026-10-21 · **Session**: 3dcfd0 · **Plan**: `plan-20261013-chord-4-0.md` Phase 20 · **Asked by**: David, 2026-10-21, "a DDD sweep of everything in this branch".

The source set is every file under `packages/` and `tools/ide/web/testing-surface/src` that `git diff main...chord-4-0` touches, tests, snapshots, fixtures, generated API pages, Markdown and JSON excluded: 311 files, four of them deleted. Each was read against seven questions:

1. **Ubiquitous language** — one name per concept across Chord, IR, platform and lang; no name for two concepts.
2. **Bounded contexts and layers** — each rule in the layer CLAUDE.md's Logic Location table gives it; dependencies inward.
3. **Aggregates and invariants** — behaviors own every mutation; no trait field written from an action, the loader, a handler or a plugin.
4. **Domain events** — past-tense names; every command emits or refuses; no silent state change (DEVARCH rule 10).
5. **Domain services** — a rule consulted by more than one mover, action or condition lives in `world-model/src/world/` (ADR-379).
6. **Value objects** — one type, one spelling, one conversion per value.
7. **Anti-corruption seams** — the IR between Chord and the loader; the IDE protocol (DEVARCH 8b).

Findings are numbered D1–D22. Where the alignment ledger already holds the finding (F1–F23, `alignment-ledger.md`), it is cross-referenced, not repeated. Each finding is a fix at its home unless marked **design question**. None is fixed: every fix touches `packages/`, and platform changes wait on David.
