One view mode was the wrong question

The layout study measured three layouts against Fernhill and picked a winner. But the right layout turns out to be a function of the shape of the suite, not of the tool — and a project can hold both shapes at once.

There is already a precedent in the decision we made: we chose Finder semantics for the columns, and Finder ships four view modes for exactly this reason. Icon, List, Column and Gallery are not indecision; they are an admission that directories differ.

Below: the two shapes a Sharpee suite takes, each rendered in both modes. The diagonal is where each mode belongs. The off-diagonal is what a single global choice forces on you half the time.

List is nearly free

TestPanelView is already an NSOutlineView whose data source is two levels deep. What it lacks is a level above — entry-to-entry parentage — which is exactly what the run-event stream's parent field now carries. List mode is that data source gaining a level, not a new surface.

Three modes, and each earns one

Column navigates a fan by path. List reads a chain in order. Documents browse peers as files and host proposals. The horizontal canvas still does not return — it lost on extent in the fan case, which is the case Column and Documents both already serve.

Where the explorer finally has a home

ADR-299 reserved origin: author | explorer on every node so a machine-proposed thread could be adopted. Nothing ever set it and no adoption UI was built across nine phases, because a badge on a tree node cannot say “read this whole path and keep it or bin it”. A document can — and the explorer emits transcript files, which is what this view is made of.

Do not auto-switch

Picking the mode from the shape is tempting and wrong: a view that rearranges itself when you add a test is a view you stop trusting. Default to Column, remember the choice per project, and let the author switch.

This retires the coalescing rule

The “a run shares a column” fix existed to make Column survive a chain. With a List mode, a chain simply is not viewed in columns. One switcher replaces a special case in the column layout — and special cases in a layout are what run-folding was.

Fernhill is the real branch-stories/fernhill suite — 22 nodes, depth 3, 12 children off arrival. The eight-way split of dawn-lose is hypothetical; it is 115 commands today and nobody has proposed splitting it. Rows in the fan panels are truncated for the mock, which is a limit of this page, not a proposed affordance.
