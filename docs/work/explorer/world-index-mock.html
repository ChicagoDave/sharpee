The Reach tab runs against a copy of that IR carrying four injected faults (key moved into the cellar, an exit pointed at a non-existent room, an object moved into the cellar, one description removed); all three finished stories in the repo — Fernhill, The Alderman, Ides of March — pass Reach unmodified. The Incomplete counts come from resolving authored noun phrases against each object's name + aka — which is the whole vocabulary a Chord object has: the IR carries no adjectives field, and the loader never populates IdentityTrait.adjectives, so an adjective is matchable only where the author wrote it into a name or an alias. Fernhill compensates by hand: all 36 of its multi-word objects carry an alias.
