### Tier 2 — the import seam, while the evidence is fresh

#301 → #302 → #287, #288

Today's port work produced #301 and #302 without anyone going looking, and
#287/#288 were already filed against the same seam. #301 is the keystone:
`Span` has no file field, so fragment diagnostics point at innocent main-file
lines. Until that is fixed, #296's Diagnosis tab and #287's Story-group
placement are both building on a diagnostic that cannot name its file, and
#302's nesting cannot be debugged at all.

### Tier 3 — phrase affordances as one feature

#281, #282, #283, #284 — tap to edit, hover to define, hold to reveal, and a
live Read tab. Four filings, one design. Worth a single session and probably a
single ADR rather than four independent changes.

### Tier 4 — hold the testing-UX cluster for the revamp

#193, #194, #198, #239, #240, #243, #244, #252, #253, #254

The current testing UX is already recorded as "too mechanical" with a full
analysis and likely revamp planned. Fixing these ten piecemeal spends effort on
surfaces the revamp replaces. Recommend they be labelled and parked against
that work rather than triaged individually now.

### Tier 5 — decide the API audit batch as a batch

leaving them open costs a re-read at every triage.
