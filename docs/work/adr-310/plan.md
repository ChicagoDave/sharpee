# Session Plan: Implement ADR-310 (character model in Chord) + ADR-318 (normative character layer)

**Created**: 2026-08-15
**Plan Status**: ACTIVE
**Overall scope**: Land both accepted ADRs as one combined implementation — ADR-310's descriptive character model (personality, mood, disposition, cognitive profile, goals, influence, propagation) and ADR-318's normative layer (temperament, principles/obligations, honor, conscience, the lie ledger, arbitration) — across the Chord compiler, world-model trait, `@sharpee/character`, stdlib's NPC/dialogue integration, story-loader/engine persistence, and the thealderman demonstration story. Combined per ADR-318 D12: its persistence rides ADR-310 D17 (all state on `CharacterModelTrait`, versioned shape), so the two do not decompose cleanly into independent plans.
**Bounded contexts touched**: Chord Story Language (compiler grammar + diagnostics), World Model (`CharacterModelTrait` shape, vocabulary modules, persistence), Character subsystem (`@sharpee/character` — arbiter, evaluation loop, dialogue selector), stdlib NPC/dialogue (tick-phase socket, ASK/TELL/SAY/TALK TO selector integration, act detection), story-loader/engine (load-time instantiation, save/restore), IDE/testing surface (author-channel introspection — "explain this NPC's turn").
**Key domain language**: personality · mood · disposition · cognitive profile · goal · influence · propagation · belief (holder, subject, facet → value) · temperament · principle/obligation · honor (face-act) · conscience (pressure band) · lie ledger (mint/pin) · arbiter · author channel.
