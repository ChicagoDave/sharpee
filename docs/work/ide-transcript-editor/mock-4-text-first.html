The file, with a gutter

ADR-300 Q1, option B. No model, no round trip. It is the .transcript in the editor Chord Writer already has, with run results painted behind the lines that produced them.

The bet: the file is preserved byte-for-byte, comments and blank lines and hand-formatting intact — and authors who already write these files by hand lose nothing. Syntax highlighting plus a results gutter is most of the value for a fraction of the work.

The cost: you are still typing brackets. [EVENT: true, 2, type="…" key="…"] is not made easier by colouring it, and D3's promise — that the whole grammar becomes authorable — goes unkept.
