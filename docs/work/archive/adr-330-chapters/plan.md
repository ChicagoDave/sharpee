Secret Letter story content itself (`branch-stories/secret-letter`).

trigger, `during`/`before`/`after <name>`, `story.chapter` channel packet, `runtime.chapter-stale`.

- **Deliverable**:

    - `visits <room> for the first time` — the one moment with **no existing readback surface**: there is no general "has the player ever entered room X" world-state key (`first time` clause tracking today is a per-clause occurrence counter, not a room-level visited flag).
