# Session Plan: Inline play-edit — type in the Play window itself (ADR-333 D4c)

**Created**: 2026-09-06
**Plan Status**: DONE (2026-09-06 ~00:35 CDT; all three phases DONE, full IDE suite 637 passing)
**Overall scope**: Extend ADR-333 D4's play-to-write (⌘-click → editor opens at span) with an inline variant: when the clicked paragraph's phrase is a single-arm template (`strategy: null`, one variant), ⌘-click swaps the paragraph in place for a text field prefilled with the template (braces included), Enter commits over a second bridge message, the coordinator replaces the span in the editor's buffer (undoable) and saves, and the existing save → build → reload → replay path finishes the round. Every other case (platform message, multi-variant/strategy phrase, unresolvable) falls back to opening the editor exactly as today — no regression to D4/D4a.
**Bounded contexts touched**: `packages/chord` (IR — read-only, no change), `tools/ide/SharpeeIDE/Compose` (decoder — additive `strategy`/`variantCount` fields), `tools/ide/SharpeeIDE/Play` (bridge script + inline field), `tools/ide/SharpeeIDE/Play/PlayToWrite.swift` (pure resolver helpers), `tools/ide/SharpeeIDE/Play/PlayToWriteCoordinator.swift` (inline round: request, commit, save, arm), `tools/ide/SharpeeIDE/Editor` (existing `replaceText`/`saveActiveDocument`, consumed not changed), `tools/ide/SharpeeIDE/MainWindow.swift` (wiring).
**Key domain language**: single-arm phrase (a `define phrase`/description whose `IRPhrase.strategy` is `null` and whose `variants` array has exactly one entry — the eligibility test for inline editing), template text (the variant's raw text with markers/braces intact, as it appears in the source, distinct from the rendered prose a paragraph shows), inline commit (the second bridge message, `playEditCommit`, carrying the field's new text plus the same `messageId`/`turn`/`history` the original click carried), span body (the source range an inline commit actually rewrites — body lines only for a `define phrase`/`override message` block, the whole span for a bare description), fallback (any phrase that fails the single-arm test opens the editor exactly as D4 does today — never a silent no-op).
