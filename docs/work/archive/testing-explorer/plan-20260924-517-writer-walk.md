# Session Plan: GH #517 — `collectStateWriters` walks every statement-bearing root

**Created**: 2026-09-24
**Plan Status**: DONE (2026-09-24, session 786899 — all three phases complete)
**Overall scope**: `packages/world-index/src/statements.ts`'s `collectStateWriters` rooted its walk at a chosen list of IR surfaces (entity `onClauses`/`topics`/`manner`, trait `onClauses` per composer, machine `states`, four story-level keys) and missed the rest — entity `timerClauses`, `moveClauses`, `exchanges`, `greetings`, `initiative`, `conversations`, and most of the story-level surface. A `when <timer> expires` clause on a gate-blocking entity is exactly the blind spot ADR-321 D4's gate-opening check cannot afford: a missed writer reads as "this gate never opens" when it does. Fix: widen the walk to cover every statement-bearing root, not a longer allowlist — matching the shape `tools/explorer-probe/lens-declared-state.js`'s `collectAllStateWriters` sweep and `entitiesMovedIntoPlay` (same file) already use. David discussed and approved this platform change (CLAUDE.md's platform-change rule).
**Bounded contexts touched**: `@sharpee/world-index` (the derivation package) — the `collectStateWriters`/Reach contract ADR-321 defines. Its consumer `tools/explorer-probe/lens-declared-state.js` (testing-explorer, ADR-294) gets its `platformGap` regression pin updated to reflect the closed gap, but is not itself redesigned.
**Key domain language**: writer, owner (`entity`/`machine`/`story`), `it` binding, statement-bearing root, gate (ADR-321 D4), `platformGap` (the lens's own sweep-vs-platform diff).
