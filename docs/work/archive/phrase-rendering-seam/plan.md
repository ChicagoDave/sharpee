# Session Plan: Fix the Chord phrase-rendering seam (#304 refusal Choice, #286 phrase-body interpolation)

**Created**: 2026-08-23
**Plan Status**: DONE (2026-08-23, session 55eedf — Phase 1 and Phase 2 shipped; Phase 3 deferred to #303 item 2's evidence gate and marked ABANDONED within this plan)
**Overall scope**: Two adjacent Chord platform bugs in the same rendering seam — a `refuse <key>` on a strategy phrase prints the literal word "variants" instead of selecting an arm (#304), and `{phrase-key}` markers resolve inside room-description bodies but are silently inert (no diagnostic) inside `define phrase` bodies (#286). Both are `packages/chord` (lexer/parser/analyzer/IR) and `packages/story-loader` (IR interpreter/evaluator/runtime) work, flagged for discussion before implementation per CLAUDE.md's platform-change rule — this plan is that discussion artifact. This is a one-to-two-session detour; `docs/work/secret-letter-port/plan.md` resumes at its Phases 4/6 afterward (already stamped "Superseded by" this plan, session 55eedf, rule 18b).
**Bounded contexts touched**: Chord Story Language only (per `docs/context/project-profile.md`) — `packages/chord` and `packages/story-loader`. No engine, stdlib, or world-model change is in scope: both bugs live entirely in how a declared phrase's variants get selected/interpolated at emit time.
**Key domain language**: phrase (`define phrase <key>[, strategy]`), strategy (`randomly | cycling | stopping | sticky | first-time`), Choice atom (the runtime's selector-bearing render payload), refusal (`refuse` / `must` / `refuse-when`), marker (a `{key}` reference inside phrase/description text), snippet (the room-description-only resolution path, ADR-211 Z2).
