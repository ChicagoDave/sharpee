# Session Plan: A story event is not prose (GH #724), and `narrate` leaves the platform

**Created**: 2026-11-19
**Plan Status**: DONE
**Overall scope**: A Chord `emit` raises a story event; the story declares its story-event vocabulary, the loader hands it to the engine once as data on the `Story`, and the prose pipeline's filter stage drops every event of those types before any handler sees it. In the same change the `narrate` rendering flag is removed from the platform, with no replacement. One patch-sized change; versions do not move in this plan.
**Bounded contexts touched**: Chord Story Language (the compiler's IR, the loader's translation of event ids); Engine (the `Story` contract, story installation, the prose pipeline's filter stage); the core event model (`ISemanticEvent`). Mechanical removal of the flag also reaches event-processor, parser-en-us, world-model, a stdlib test, Dungeo and the family-zoo-tutorial story.
**Key domain language**: story event (an event the story raises with `emit`; not prose); story-event vocabulary (the set of types a story can raise, declared once); prose pipeline filter stage; domain event (a past-tense fact, carrying no instruction about how it is rendered).

## Decisions this plan takes as its recommendations (David confirms or overrides before Phase 1)

1. **Where the vocabulary comes from**: the compiler records it. The analyzer mints every `emit` IR node at two places (an authored `emit`, and the media statements' lowering), so a list filled there is complete by construction and stays typed. The IR gains a required list of the Chord event ids its `emit`s name, sorted, each once; `IR_FORMAT` moves to `story language 7` (ADR-388's precedent: a patch, language version unmoved). The alternative is a loader-only typed walk over every statement-bearing IR family (about fifteen of them), with no IR change but completeness held only by a test.
2. **Mapped platform names are in the set**: the vocabulary is every name the story's `emit`s raise after `translateEventId`, the `media-*` names included. The guarantee is about the statement (an `emit` prints nothing); no media type renders prose today, and including them closes a media `emit` carrying a field named `text`. The alternative keeps the set to ADR-256 D3's unmapped author events.
3. **Name and shape**: `storyEvents` on both the IR and the `Story` contract; on `Story` it is an optional `readonly string[]` of runtime event types (absent means none, as for a TypeScript story such as Dungeo). The engine hands it to the prose pipeline through a new install step over a new install-context collaborator, the prose pipeline, which keeps it as a set; the filter stage drops any event whose type is in it. A pipeline swapped in later by `setTextService` receives the installed story's set too.
4. **The loader's `narrated()` is deleted** (nothing reads the flag it stamps); its six call sites return the statements' events directly.
5. **ADR**: if David says the decision is ADR-worthy, Phase 1 opens by writing ADR-405, "A story event is not prose", recording the concept, the `Story` field, the filter rule, and that a domain event carries no rendering flag.
