## Sequencing note
Phases 1 → 2 are sequential by real dependency: the ADR's Context is Phase 1's measurement, and no implementation phase starts before the record is ACCEPTED (steps 2-6's shape). After that the dependencies are narrower than the numbering suggests. Phase 3 (the table contract and its first readers) precedes Phases 4 and 5, which add list words, sentences and directions to the contract it creates. Phase 4 and Phase 5 are independent of each other. Phase 6 (instance state) is independent of 3-5 in code and may run first, which is the order of least text exposure: it moves no word list and should move no output line, so it can land early and prove the per-instance seam before the tables ride on it; the numbering puts the tables first only because F1 is the largest finding. Phase 7 depends on the ADR's rulings on F4 and F5 and on the table existing (3, 4, 5). Splitting this way attributes each text move to one decision: Phase 3 (articles and self words), Phase 4 (list words and sentences), Phase 5 (directions), Phase 6 (none expected), Phase 7 (Chord surface). Phase 1 is first because the review's F1-F5 line numbers predate steps 2-6, which deleted or moved several of the sites, and the Dungeo and tree exposure is inferred from code and unmeasured.
