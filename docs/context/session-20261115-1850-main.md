## Key Decisions

### 1. A machine's action trigger is its thing's answer to the verb (David: "b" of three options)
Fixing the engine alone would have left self-dispatching verbs refusing a thing with no clause of its own; the trigger now counts as that thing implementing the verb, so a machine-only crank turns.

### 2. A sound says nothing the author did not write (David: "b")
The platform's default "You hear <name>." line never stands in for an author: a sound with no `heard:` line is silent in prose, though still heard by listeners and still played.

### 3. An empty kind template is silence, not a fallback (David: "yes")
The engine's audibility handler checks `provider.getTemplate?.(kindId) === ''` before the phrase path, so an empty registration ends the render rather than falling through to `sound.heard.default.<tier>`.

### 4. `emit` takes one word; the change rides the unpublished 4.0.3
A removal of a form that compiled, recorded in `packages/chord/tests/language-version.test.ts` as a dated ebnf hash re-pin with no version bump; the sound block is additive on the same surface.
