## Key Decisions

### 1. Kindle is the standard lighting action with a verb added, not a story action
`change it to lit` compiles but writes a shadow story state (#707), so no story action can light, open, lock, switch or un-break anything; kindle is `extend action lighting` plus message overrides, and the lens got its own `cracked, sound` states so `change` can mend it.

### 2. No `wick` trait
A trait's `on the player lighting` silently drops the composing thing's own `on` and `after` clauses for that gerund (#708), so the lamp, candles and Lantern each repeat one requirement line.

### 3. The candles stay one thing and `each` stays out of the game
Lighting several things in one casting needs `change … to lit` to mean something; the three candles and `each` return when #707 is fixed.

### 4. A one-carrier trait is normal
A thing may not answer a story action in its own `on` clause, so the grille's answer to unbind is the `ward` trait though nothing else carries it.
