## Completed

### ADR-264 — Chord numeric counters (DRAFT)
`docs/architecture/adrs/adr-264-chord-numeric-counters.md`. A generic raisable named number
spun off from ADR-263 Q-4 (sanity's madness needs it; hunger does not). Proposed grammar:
`define counter <name> [starts n] [between lo and hi]`, `raise`/`lower <counter> by <n>`,
counters read in conditions, persisted as world state (the ADR-263 `hunger.severity` seam),
composing with the ADR-262 banded engine (a `use sanity` meter = a counter + a band ladder).
Context pins why none of `award` (dedup-by-identity), `change` (named states), or `score`
(the ledger) is an additive counter. Six Open Questions in the shared adr-interview contract
format (declaration explicit-vs-inferred, clamp semantics, per-entity scope, vocabulary, the
`use sanity` binding, arithmetic beyond ±). Left DRAFT — warrants `/devarch:adr-interview`.

### ADR-265 — stdlib in readable Chord form (PARKED → ACCEPTED)
`docs/architecture/adrs/adr-265-standard-library-readable-chord-form.md`. Un-parked with the
owner's decision. Five decisions: D1 the entire core stdlib rendered in Chord form; **D2 explicit,
machine-checkable reference-only notation** (marker banner + structural flag, enforced — loader/CLI
refuse to load a reference as a real story, a missing marker fails the build); D3 generated from
ADR-228 action metadata (stays honest, not hand-written); D4 paired with the real change seams
(`override message` / interceptors / event handlers); D5 the real stdlib stays TypeScript — a
projection, not a port (rejects option B). Prior PARKED A/B/C analysis retained as rationale.

## Key Decisions
1. 264 and 265 are distinct: 264 is a language primitive; 265 is a reference/projection of the
   stdlib. They do not couple (265 renders standard *actions*, not author grammar).
2. ADR-265's load-bearing constraint is the enforced reference-only marker — the readable Chord
   stdlib must never be mistakable for, or loadable as, the implementation.
3. ADR-264 stays DRAFT pending an interview; ADR-265 is ACCEPTED (owner decided in session).
