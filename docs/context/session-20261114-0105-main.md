### #718: the generated browser page (uncommitted, staged by the next commit)
1. **Panel and image slots were never visible.** New `packages/platform-browser/src/channels/slot-visibility.ts` exports `revealSlot` and `concealSlotWhenEmpty`, and `channels/panel.ts` and `channels/image.ts` call them. `packages/devkit/templates/browser/index.html` gains a hidden `#sharpee-media` above the prose pane and a hidden `#sharpee-sidebar` beside it, inside a new `.sharpee-body` row. `BrowserClient.adaptHostLayout` creates any missing slot next to the prose pane and finds the layout root with `closest('.sharpee-window')`.
2. **The image had zero height.** `styles/base.css` gives `#sharpee-media:not([hidden])` a default height of `min(40vh, 320px)`. Rules for the sidebar and panel are added to `base.css` and `engine.css`.
3. **The audibility channel leaked onto the page.** `channels/index.ts` registers an exact-id renderer for `audibility` that draws nothing, because the prose pipeline already narrates it.
4. **Mode append into a named element.** `panel.ts` appends one child per primitive value: an `li` in a `ul` or `ol`, otherwise a `span.sharpee-channel-entry`. The build warning in `packages/devkit/src/standalone/browser-core.ts` is reworded.
5. **`sharpee build <dir>` refused a story directory.** New `packages/devkit/src/build-target.ts` (`projectDirectoryFor`) is used by `packages/devkit/src/cli.ts`.
