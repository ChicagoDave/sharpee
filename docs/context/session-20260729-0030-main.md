## Key Decisions

### 1. Chord goes to 2.2.0 — a minor, and the fourth recorded departure from D2's letter
D3/D5/D6 each stop previously-valid stories from compiling, which ADR-257 D2's versioning rule literally calls a major. David ruled (owner decision, this session): breaking changes are acceptable at this stage and need not be paid for with a major, following ADR-276's `2.1.0` precedent exactly (new compile gates, `chord.ebnf` untouched, pin hash standing). Lockstepped with Sharpee 4.3.0 (the next publish, confirmed by David); ADR-278 keeps its `3.0.0`/`5.0.0` reservation for Relations. Corpus check: a scan of all seven shipped `.story` files found no duplicate `define action`/`define trait` and each declares exactly one `starts in` — no shipped story trips the three new gates. Misstep, corrected before acceptance: I first misread David's "we're still in breaking change territory" as a ruling FOR the major and wrote that into the draft; he clarified and it was fixed.

### 2. Open-questions interview resolved three design gaps before review
Via `/devarch:adr-interview` (rule 11a), one question at a time, each folded immediately: Q1 (open-condition state vocabulary) → D10 widens to the union of declared states, matching the `the match` precedent, verified `symbolHolds` (evaluator.ts:251) already resolves per candidate so this is analyzer-only; Q2 (placement) → D4 unifies by deleting two special cases rather than adding two gates; Q3 (occurrence counters) → reset + sweep, explicitly no save-format version and no migration reader, because a faithful migration cannot be written — the old key space was colliding, so migrated values have no correct destination.

### 3. Two review passes each caught something the other missed
First `adr-review`: 11/14, two BLOCKERs folded — the sweep glob `chord.occurrence.select.*` would have deleted the new key space it just created (fixed: sweep `/^chord\.occurrence\.select\.\d+$/` only, bare-digit ids reserved, runs on restore too, not just load); D2 added a required IR field with no `IR_FORMAT` bump or loader backstop (fixed: `IR_FORMAT` → `story language 2` + a LoadError for an id-less select). Second `adr-review` (after cross-ADR seam work below): 13/14, one BLOCKER — the ADR claimed "stories that compile today compile identically," which D3/D5/D6 directly contradict; this became the versioning decision above.

### 4. Cross-ADR seams and David's own cross-check both surfaced follow-on obligations
ADR-276's audited census ("all 50 loader.ts LoadError sites are backstops or D5 residue") grows by two and must be re-audited in the same commit as implementation; ADR-275 D6's "refuse when arm" wording was disambiguated against D3 (it means an unbound subject binding, not a select arm). Separately, David's own cross-check caught that the review's `isStatementLine` design concern was sitting unrecorded rather than deferred; checking that seam turned up four more items in the same state (table-driven `parseCreate` dispatcher, version-history table, non-null assertions, `as never` span casts). D8 was widened from "the numbered lows" to a disposition of the entire review, and AC-22 now requires that completeness.
