## Key Decisions

### 1. Location-heading equality belongs on branch-tester, not transcript-tester
Sharpee's `.transcript` suite is a Dungeo-authored regression suite and not a Chord design input (per standing project direction); AC-3's cross-source equality claim is a Chord/branch-story concern and branch-tester already owns the tree document AC-11 cites. Adding it to transcript-tester would have put a platform-design assertion inside a story-specific test suite.

### 2. Arm predicates move to a registry, not a trait
`IFEntity.toJSON` serializes every trait field through `JSON.stringify`, which silently drops function-valued fields (`packages/world-model/src/entities/if-entity.ts:433`), and `trait-rehydrator.ts` only restores prototypes for registered core types — never per-instance closures. Storing conditional-heading predicates on a carrier trait would make every arm unconditional after RESTORE, with the first arm winning permanently. `registerSnippetGate`'s module-registry pattern (explicitly documented as "nothing here is serialized") is the precedent that actually survives save/restore, so D16 contract 2 was rewritten to match it rather than the trait shape D16 originally cited.
