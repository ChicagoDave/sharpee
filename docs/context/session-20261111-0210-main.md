## Key Decisions

### 1. Flag-entity references count over the whole IR, skipping `identity`
Counting every id-equal string can only withhold the warning, never add one. The save manifest had to be skipped because it names every entity.

### 2. A thing nothing references is not a flag entity
The rule needs at least one `change … to` or `is` use, so this warning does not double as an unused-entity lint.

### 3. Declare out-of-package reads per package, not as global dependencies
A read declared as a `globalDependency` would invalidate all 33 test tasks on every story edit. Per-package `inputs` keep the invalidation narrow. For example, a thealderman edit re-tests 3 packages, not 33.

### 4. Name gitignored build outputs as inputs, and exclude build trees from story globs
turbo hashes a gitignored file that `inputs` names, so a stale or rebuilt bundle re-tests its readers. A glob without exclusions would pull every `dist/` and `node_modules/` under a story into the hash.
