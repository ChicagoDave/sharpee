## Key Decisions

### 1. `change` to a platform state word is the author's fiat on the trait (ADR-399 D1–D5)
David's "a": no key, fuel or power check and no event; a declared state wins the word; a thing without the trait is a compile error (`analysis.change-state-pairing`) or, for `the match` and slots, a failed command naming the trait.

### 2. One-word shadow gate (ADR-399 D6)
A thing that carries a state trait may not declare one of that trait's words; without it D2 and D3 would let a stored `open` answer `is open` after `change … to closed` wrote the trait.

### 3. Switch and flame move together (ADR-399 D7)
On a switchable light source the four words write both fields, matching the standard switching actions; `starts` shares the table, so `starts lit`/`starts on` set both too.

### 4. No grammar change
Chord's working number stays 4.0.3; no EBNF change.
