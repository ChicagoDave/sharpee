## Key Decisions

### 1. Split Phase 3 rather than pad the estimate to fit the 400 budget
The plan's own text pre-authorized this ("if the estimate below reveals a cost this budget can't cover, split at that point rather than padding the estimate to fit"). The estimate found the Windows half categorically different in kind (a second assembler, not an extension), not just larger — splitting kept Phase 3a small and macOS-only while Phase 3b inherits the full original budget rather than a diminished one.

### 2. Drop the `import` condition on `bridge`/`runtime` instead of building `dist-esm` for them
Both packages promised `exports["."].import` with no `dist-esm` directory ever having existed. Verified no in-repo consumer resolves either through the `import` condition before making the change (David's ruling, confirmed safe by grep + the runtime's plain `<script src>` load path).

### 3. Rule out the third `execSync('npx tsc')` site rather than fix it
Fixing it would have meant adding a `typescript` dependency to devkit for a code path the Chord build never reaches (`build.ts:98` returns before `:122`). David's ruling closed this as a non-issue rather than a deferred fix: "everything we're doing is for Chord."
