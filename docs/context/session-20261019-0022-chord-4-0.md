## Key Decisions
- Coordinates are one `position: {x, y} | null` field (both-or-neither is the D5 invariant), not two nullable numbers as the proposal text had.
- `heading` stays `string | null`; ADR-375's bearing widens it in Slice 6.
- A course whose first leg heads into `atEdge` is refused like a heading (D8 names headings only; the same rule, stated here).
- `sightBandOf`, not `bandOf`: the world barrel already exports `bandOf` for banded scalars (ADR-262).
