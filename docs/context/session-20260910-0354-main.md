## Key Decisions

### 1. Lifecycle states named as conditions, not outcomes
David's grammar question during the interview settled the four states as `empty → ready → playing ↔ stopped` — conditions, not event-outcome names.

### 2. Stop reason stays an emitted event, not duplicated on the phase
David's reasoning: it already reaches a message list; duplicating it on the phase state would repeat the exact proxy-field-sprawl complaint the ADR itself raises.

### 3. `restart` is engine disposal, not a phase transition
Keeps the phase model to the four states above rather than adding a fifth.

### 4. D12 fixes a live rule-10 violation in `resume()`
`resume()` currently sets `running = true` and emits nothing; on the transcript-tester's RETRY path a session can go dead-to-live with no stream record. D12 adds a `game.resumed` event.

### 5. Two `adr-review` findings landed against the ADR's own draft text
An unverified "all three restarting hosts" claim in D10 (only one host actually has a restart path) and no named amendment owner for ADR-344 D6a — both folded before acceptance.
