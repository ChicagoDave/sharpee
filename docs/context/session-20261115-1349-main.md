## Key Decisions

### 1. A beat prints before the answer, as its own paragraph (David, 2026-11-15, option A)
A beat is stage business that leads into the line it colours; `placeMannerBeats` splices it ahead of the answer event, and it prints only when its wire event is in the report, so print and wire cannot disagree.

### 2. Manner reaches every spoken delivery (David, 2026-11-15, option A)
Table rows, greetings, exchange answers and thread lines all select a beat; this is why table answers now carry an utterance wire event.

### 3. adr-320-phase7.test.ts expectations follow the change (David, 2026-11-15)
The beat event is now first in a coloured report; the old helper's "first event is the answer" assumption was an artifact of the gap.

### 4. A rendered silence prints its beat and then the action's default line
Correction made to David: a silence prints the beat followed by e.g. `You answer, "no."`, not the beat alone, because that default already stood for a silence before this change.
