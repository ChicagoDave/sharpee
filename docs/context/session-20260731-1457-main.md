## Key Decisions

### 1. ADR-291 ACCEPTED (2026-07-31, this session)
Reviewed twice: 9/16 with two BLOCKERs, then 16/16 clean. The two BLOCKERs: (a) the authority's home package was unnamed and D2 as first written had world-model import the engine, violating ADR-231 D6 — fixed by adding D2a; (b) no interface contract existed for the authority or for D8's directive.

### 2. Interview answers that reshaped the ADR rather than filling a blank
David's "we need a way to trigger the variations" produced D9's four modes plus the rule that every run reports its seed and every failure names the seed that produced it — the property that makes exploration convertible into a pinned regression test. D6's allowlist emptied to zero once event ids were traced into the save file.

### 3. Two interview questions settled by reading code mid-interview
Zifmia has no `event.id` dependency, freeing the deterministic-id ruling; `AudioRegistry.resolvePool` bakes random values into an event payload rather than applying them at playback, which makes the audio stream a correctness matter rather than a presentation preference.

### 4. `--sweep`/`--chain` resolution
A per-file seed is incoherent for a chain (one session, one world — RNG doesn't reset at file boundaries), so the resolution is seed-per-session, with a chain deriving its seed from its first member.

### 5. ADR-291 records a "Deferred, not decided" section
Two residual review notes carried forward unresolved: D6's gate scope vs. `--vary`'s clock read, and the IDE's lack of a seed-entry touchpoint.
