## Key Decisions

### 1. Own clauses first, every binding consulted (ADR-118 Amendment 1 A1-A5)
David's ruling "A": the specific outranks the generic, so a thing's own clauses and topic table run before composed traits, and a false guard falls through rather than shadowing.

### 2. A stated order is a priority (A6)
`, before <trait>` / `, after <trait>` become registration priorities, an own clause marked `, after` moves to a late marker trait, and impossible or unplaced orders are load errors rather than analyzer diagnostics; this mechanism was built and reported to David after the fact (GH #745).

### 3. Attacking resolves from whichever binding leaves an `attackResult` (A7)
With several bindings consulted, the combat contract could not stay "the" target consultation; built and reported after the fact, not ruled beforehand (GH #745).

### 4. `clause-order.ts` lives at `packages/story-loader/src/`, not `src/runtime/`
`tests/runtime-sections.test.ts` ("a section imports only the core among its siblings") failed with the module under `runtime/`; the session stopped, reported, and on David's "proceed" moved the module, leaving the structural test unchanged.
