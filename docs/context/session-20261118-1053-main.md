## Key Decisions

### 1. A RESTART's opening is a new opening, apart from the restart command
The command's `lastOutput` stays the acknowledgement and the opening's packets replace `openingPackets`; a head that prints the opening tells a reboot by the array's identity changing.

`openingPending` decides, so a chain opens once and a restored or already-commanded game is left alone.
