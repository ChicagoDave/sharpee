## Key Decisions
- **Position identity for an all-paths blessing = the node's command** (trimmed, case-folded — as a parser
  reads it). D3/D4 say a blessing can be invariant "at a story position", but ADR-299 explicitly does NOT
  model convergence ("the figure eight was a metaphor… not a modeling requirement"), so the skein tree carries
  no notion of "the same place" beyond commands and outputs. An all-paths blessing therefore asserts: *every
  node in this skein carrying this command prints this output*. The bless flow states the claim back in those
  words, so a claim the author did not mean (blessing `look` for all paths) surfaces as a finding they can
  downgrade, rather than a check that silently never fires. Consequences: a plain blessing constrains only its
  own node; a node is never a finding against its own blessing's scope; two disagreeing all-paths blessings
  are reported from both sides rather than picking a winner.
- Replay reporting follows the objection: findings send the author to Transcript, not Play. A first-class
  finding hidden behind a running game is a silent diff with extra steps.
