## Key Decisions
1. **Catalog anchored on `globalThis` via `Symbol.for`**, not module scope: core ships dual CJS/ESM builds, so a plain module-level `Map` could yield two catalogs in one process, violating the A1 ruling-6 process-global invariant. One line of mechanism, no new dependency.
2. **Idempotency = exact redeclaration only** (same name, identical class list, or both plain draws): returns the original handle. Any divergence throws — the catalog never mutates an entry (D2 immutability).
3. **Pinned values generated from the real source function** before the test was written (scratchpad esbuild run), closing the confidence-laundering hole `pre-session-audit` flagged: a wrong hardcoded expectation would otherwise look exactly like that recurring pattern.
4. **No trace/coverage report types yet** — the ADR's core touchpoint lists them, but the plan's Phase 1 deliverable deliberately does not; they belong to Phase C's surface and nothing in Phases 2–7 of this plan consumes them.
