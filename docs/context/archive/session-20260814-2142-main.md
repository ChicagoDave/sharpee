## Key Decisions

### 1. Relocation of DevArch runtime state is not available to this repository
All four runtime path writers/readers are upstream DevArch code (`~/.devarch/hooks/*`), hardcoded and overwritten on `devarch update`. The only disposition left to this repo is retention pruning, which is what shipped. This closes P-10's investigation branch rather than leaving it open for a future session to re-derive.

### 2. Never infer "untracked" from a gitignore match — check `git ls-files`
The prune script's first version treated "path matches a `.gitignore` pattern" as proof of "safe to delete," and it deleted two files git had tracked since before the gitignore rule existed. Fixed to check `git ls-files` directly and skip anything tracked. This is the fourth time this plan's phases hit the same proxy-signal shape (see Notes) — worth treating as a standing lesson for any future cleanup script in this repo, not just this one.
