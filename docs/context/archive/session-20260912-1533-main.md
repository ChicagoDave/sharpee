## Completed

### 1. `repokit` runs on Windows (main deliverable)
Diagnosis: `repokit` shelled out via `execFileSync` to Node-ecosystem CLIs that are `.CMD` shims on Windows. Session 89f9e0 had identified 3 call sites; the real count was **11 across 7 files**.

Measured on this box (Windows 11, Node v24.19.0), which drove the design:
- `execFileSync('pnpm', ['--version'])` → ENOENT
- `execFileSync('<abs>/node_modules/.bin/tsf', [...])` → ENOENT (extensionless POSIX shim)
- `execFileSync('<abs>/node_modules/.bin/tsf.CMD', [...])` → EINVAL (Node's CVE-2024-27980 hardening: a `.cmd`/`.bat` can only launch through a shell)
- `execFileSync('<abs>/node_modules/.bin/tsf.ps1', [...])` → EFTYPE

`shell: true` with an args array was rejected on evidence: Node 24 deprecates it (DEP0190), emitting a stderr warning per call that the AC-13 CLI real-path test treats as failure noise, and it leaves args unescaped. The working shape is ONE pre-quoted command line with NO args array — verified to round-trip `!@sharpee/repokit`, `a&b`, `c^d`, `e f`, `pipe|d`, `paren(s)`, `quote"d`, `back\slash`, and a directory whose name contains a space, and to still throw with `status` set on a non-zero child exit.

Files:
- NEW `tools/repokit/src/proc.ts` — the single subprocess seam (`runTool(cmd, args, opts)` + `resolveTool(cmd)`). POSIX behaviour is byte-identical to the previous direct call. On Windows it resolves a bare name or extensionless bin path through PATHEXT, and routes only `.cmd`/`.bat` through a shell as one pre-quoted line.
- NEW `tools/repokit/src/proc.test.ts` — 10 real-path tests (rule 13a: the subject IS the subprocess layer, so a mocked `execFileSync` would only assert we call ourselves). Each spawns a real shim off disk from a space-bearing directory.
- MODIFIED, 11 call sites routed through `runTool`: `commands/build.ts` (4), `commands/bundle.ts` (1), `commands/clean.ts` (1), `commands/verify.ts` (2), `commands/test-npm.ts` (1), `commands/browser.ts` (1), `consumer-gen.ts` (1). None imports `node:child_process` any more.
- MODIFIED `commands/build.test.ts` — its recorder assumed every spawn carries an args array (POSIX-only); it had been green on macOS and failed the moment the code began working correctly on Windows. Normalized both spawn shapes to `{ cmd, args }`.
