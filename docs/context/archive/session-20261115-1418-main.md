## Key Decisions

### 1. Parting is spoken by `going`, not by the tick (David, option A)
`going` closes the actor's scene on a successful move so the `on parting` line prints before the new room's description; the tick closes a player scene left by any other means with nothing said, since the speaker is already out of earshot.

### 2. Existing sound assertions follow the change (David: yes)
The 11 assertions that expected a `speech` sound for a line said to the player were rewritten to assert on the spoken-line event rather than kept as a constraint.

### 3. NPC overhearing goes through per-actor perception, not a sound carve-out (David)
David rejected an `ISound` listener-exclusion patch: PC and NPCs now run all actions the same (ADR-328), so the perception service should run the same for both, with NPCs perceiving through the observer. Agreed ADR-worthy; the per-actor perception ADR is to be drafted next and is not yet written.
