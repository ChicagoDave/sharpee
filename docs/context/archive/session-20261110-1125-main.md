## Key Decisions

### 1. Pure subpath export instead of a bundler-only alias
`@sharpee/chord/clause-ids` is a real package subpath, so every consumer (tsc, vitest, esbuild) resolves the same pure module and the barrel never enters the testing surface; this follows the existing story-loader `./pin-grammar` precedent rather than inventing a new pattern.

### 2. Guard the bundle's inputs, not just the one import
The `onEnd` metafile guard refuses to write `surface.js` when any input comes from outside a `src/` tree, so the next dist-esm leak fails the build instead of silently bloating the committed bundle.
