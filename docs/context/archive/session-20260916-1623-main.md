## Key Decisions
- **[ADR-352: How the protocol types are generated](../architecture/adrs/adr-352-protocol-type-generation.md)**
  — ACCEPTED, written this session at David's request. Records how ADR-341 D5 was carried out:
  one command and one gate (D1), one model with per-language emitters (D2), the Story IR
  projection declared in TypeScript in the build tool rather than in `@sharpee/ide-protocol`
  (D3), wire shapes only in the generated file (D4), refuse-rather-than-drop (D5), and naming
  differences owned by the target language (D6). No Open Questions.
- **The IR projection lives in `tools/repokit`, not `packages/ide-protocol`.** The shells decode
  ~20 fields of a 1,700-line schema; that subset had to be declared where a type checker sees
  it. It is not a wire type: the platform emits the whole `StoryIR`, and narrowing is a
  consumer-side concern belonging to the generator. So **no `packages/` source changed** and
  ADR-341's Scope ("no `packages/` change beyond the generator's read of `ide-protocol`")
  holds as written. Only `tools/repokit/package.json` gained deps (`@sharpee/chord`,
  `typescript`).
- **The drift guarantee was demonstrated, not asserted.** Renaming `isPlayable` in the
  projection fails `tsc` with `Type 'boolean' is not assignable to type
  '{ PROJECTION_IS_NOT_A_NARROWING_OF: StoryIR; }'`; restored, clean. The memory note
  *IDE decoder follows IR fields* — an IR rename breaking `ComposeDiagnostics.swift` silently
  — stops being true.
- **C# flattens nesting the Swift keeps** (`ComposeStoryIRMeta`, not `ComposeStoryIR.Meta`):
  C# forbids a nested type and a property sharing a name, and most of these shapes are named
  after the property that carries them. The Swift shell keeps nesting because its call sites
  already spell it that way; nothing in C# spells these yet.
- **AC-6 deviation, recorded not waived.** Two Swift test sites needed a change — the
  phrasebook is now the wire's map, so the phrase key is the dictionary key rather than a
  struct field. David approved each before the edit. The alternative was a `PhraseSet` shim
  with the custom decoder this phase removed.
- **ADR-341 not amended** — its own text says it is not edited while ADR-351 is DRAFT.
- Two fields the hand-written mirrors had lost are now present in both shells:
  `ProjectManifest.hatchContextVersion` and `Span.file`. Found by generating, not by review.
