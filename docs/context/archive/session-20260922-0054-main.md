## Key Decisions

### 1. The neutral name is primary, the WebKit address is the fallback
David's call ("go"). This is what let the change land without touching the shipping Swift app: it registers real `WKScriptMessageHandler`s, so it is served by the fallback unchanged. A later, optional step installs the neutral name there and deletes the fallback.

### 2. The bridge never serializes
The channels disagree on payload type by design. Caught before shipping — a stringified body would have failed `DocsTabViewController`'s type guard silently rather than throwing. Now stated as an invariant in the module header, not left as a convention.
