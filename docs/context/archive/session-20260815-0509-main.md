## Key Decisions

### 1. `believes` → `convinced` rename REJECTED
David: "uncertainty is not an absolute, so `believes` is more accurate." The naming collision with the removed `Belief` type resolves from the other side instead — the `_beliefs` fold removes the builder method — and Chord spells the construct `thinks`. Recorded in ADR-310 D14 (amended), `contracts.md` §6, and `plan.md` Phase 1 entry state.

### 2. Vocabulary freeze APPROVED
David: "frozen." `contracts.md` status flipped to FROZEN; both Phase 1 review gates (D11a normalization scope, vocabulary freeze) discharged.

### 3. Single `'character-model'` tick-phase registration
Rather than each of propagation/goal/influence registering its own tick-phase slot, one `'character-model'` registration runs ordered sub-steps internally — and `CharacterPhaseRegistry`'s existing mutable-state side path (its own `toJSON`/`restoreState`) is relocated fully onto the trait, per ADR-310 D17's "all state on the trait" rule.

### 4. `_beliefs` fold — resistance onto `Fact`
The old standalone `Belief` interface is deleted; belief resistance becomes an optional field on `Fact` instead of a parallel structure, simplifying the D14 confidence-word model.

### 5. Temporal ADRs do not gate this work
ADR-317 leaves `NpcService` untouched (tick-phase socket is safe to build now); ADR-316 is deferred; two amendments (platform-internal socket signatures, single clock seam) keep the door open for both without blocking on them.
