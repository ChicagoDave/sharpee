## Key Decisions

### 1. The claims identity is built by exclusion, with a written ignore list
Identity hashes everything the list does not name, so a forgotten field costs walk time and never soundness. The list leaves out the random cursor, the firing counters and `textState` by David's "B". On Fernhill, keeping them in meant no two states ever merged. Recorded as ADR-365's 2026-11-12 note.

### 2. `start-outside-set` rides the wire as settledBy `budget`
The verdict reaches the wire as settledBy `budget` with that stop reason, so `packages/ide-protocol`'s unions and the IDE stay untouched.

### 3. The claims report carries no wall-clock time
The report is the same on every run at one seed, so a byte-compared line no longer moves (#587).

### 4. The survey instrument is on demand and asserts no time
It lives under `scripts/perf/`, outside `scripts/__tests__/` and every turbo task. It commits counts and digests, never milliseconds (ADR-395 D7, D8).

### 5. Undo snapshots are switched off per game, decided from the commands it will run
A game whose lines can type `undo` keeps its snapshots. The engine's default undo depth for play is unchanged.

### 6. The actor index stores no holder
Invalidation is by a trait-membership epoch plus a counting entity map, and the flag is read live, so ADR-390 D1 holds as written and needs no amendment.
