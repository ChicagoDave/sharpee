## Key Decisions

### 1. One packet per routine is built by `ChannelService.build({ only })` (item 2)
Stripping a full packet in the engine does not hold, because `build` caches every channel's value as sent; this reaches `packages/channel-service`, outside ADR-404's Scope line, and Phase 8 widens the Scope.

### 2. The look's packet carries every turn channel except `prologue` and `banner` (item 3)
A block with no `do-first-look` sends no status channels until the first command.

### 3. A meta command's packet is stamped `currentTurn - 1` (item 4)
The `turn` channel reads 0 for a meta command typed first and 1 after one command.

### 4. `do-first-look` enters through `executeAsActor` with `if.action.looking` (item 6)
It skips the parse, the parsed-command transformers and the command validator and lands in the same `runPhases`; this departs from decision 9's wording and goes to Phase 8's "As built".

### 5. The routine writes the prologue; `start()` does not (item 10)
The TRANSITIONAL first-input write keeps every head byte-identical until Phase 6.
