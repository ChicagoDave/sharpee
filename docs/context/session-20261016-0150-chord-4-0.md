## Completed

### world-model
- `VehicleTrait` now carries only `model?: VehicleModel` (line `{stops, oneWay}` or `streets`). The constructor rejects a line with fewer than 2 stops or a repeated stop, and copies `stops`.
- Retired fields and API: vehicleType, transparent, blocksWalkingMovement, requiresExitBeforeLeaving, isOperational, notOperationalReason, currentPosition, positionRooms, movesWithContents, moveVehicle, canVehicleMove, canActorLeaveLocation, canActorWalkInVehicle.
- New `vehicleBehavior` helpers: `goingFromVehicle`, `admitsVehicle`, `isStop`, `currentStop` (derived from location), `moveVehicleToStop`. `RoomTrait` gained `admits: string[]`.
- `VisibilityBehavior.getDescribableLocation` uses one enclosure rule: only a closed, openable, non-transparent container entered `in` blocks sight. Lidless containers and supporters now show the room.

### stdlib / lang-en-us / chord / story-loader
- `going`: a line yields a `vehicle_ride` refusal, no model yields `vehicle_cannot_walk`, streets steers the vehicle into rooms that admit it (every computed-exit candidate must admit), otherwise `vehicle_cannot_go`. Messages in `going-messages.ts`; stock lines in lang-en-us `going.ts`; aliases in chord `message-alias-catalog.ts` and story-loader `message-alias-map.ts`.

### Dungeo and fixtures
