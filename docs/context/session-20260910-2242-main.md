## Key Decisions

### 1. "Tabled" is a third disposition, distinct from rule 18b's "still live"
Rule 18b's "still live" stamp is for interruptions with a returning pointer (another plan takes `.current-plan` temporarily, this one resumes). The secret-letter-port went on hold indefinitely on 2026-09-09 with no returning pointer — there is nothing to point back to it — so the plan-staleness sweep was re-prompting a disposition David had already made. Tabling records the pause inline (a `**Tabled**` header, phases DEFERRED with their entry state preserved) without pretending the plan is either still actively worked or terminal.

### 2. Per-package `tsc -p <pkg> --noEmit` over `tsc -b` for the typecheck gate
`tsc -b` (project references build mode) was the more "correct" TS idiom but the session found `tsc -p <composite-tsconfig> --noEmit` now works cleanly on TS 5.9.3 (the TS6304 failure that used to force `-b` is gone), so the gate could be wired per-package through turbo's own dependency graph (`dependsOn: ["^build"]`) instead of restructuring 42 tsconfigs for a `-b` graph. Falsification probes in `core`, `bridge`, and `stories/dungeo` confirm each package's own compiler surfaces errors independently.

### 3. Ambiguous evidence (bridge/runtime) is filed as a question, not resolved by inference
`packages/bridge` and `packages/runtime` show two contradictory signals — zero consumers anywhere in the repo, yet ongoing mechanical edit activity. Rather than guess at intent (dormant vestige vs. active prep for an unlanded consumer) and either wire them into `PLATFORM_PACKAGES` or flag them for removal, the session filed GH #409 and left the packages exactly as found. This follows the project's standing pattern that content and direction calls on ambiguous repo state are David's, not inferred.
